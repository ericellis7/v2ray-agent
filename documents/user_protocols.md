# 从已安装协议选择用户授权与订阅

创建用户只需输入账号信息并选择协议组合，不需要重新安装协议、申请证书、配置域名、端口或 REALITY 密钥。协议安装一次后，多个用户复用这些服务端配置。

## 协议列表

脚本从当前已安装的入站配置生成选择列表，不再固定三种协议或固定编号。支持原脚本具备用户订阅能力的 Xray VLESS、VMess、Trojan，以及 sing-box VLESS、VMess、Trojan、Hysteria2、TUIC、Naive、AnyTLS 入站。WS、gRPC、HTTPUpgrade、XHTTP、TLS、REALITY 等实际已安装组合会分别列出。

内部转发入站不参与用户选择。SOCKS 分流服务不属于这里的订阅协议列表。

列表中的编号是本次操作的菜单编号，不是安装菜单里的协议编号。安装或卸载协议后，列表及编号会相应变化，请以当前屏幕为准。

例如，当前显示四种协议时，用户 A 可以选择 `1,3`，用户 B 可以选择 `2,4`，用户 C 可以选择 `1,2,3,4`。不同用户的组合可以交叉。

## 新增用户

运行修改后的脚本，选择主菜单 `7.用户管理` → `4.添加用户`。

1. 输入用户数量。
2. 输入 UUID 和用户名，均可回车随机生成。
3. 从当前已安装列表选择一个或多个编号，使用英文逗号，例如 `1,3`。回车选择列表中的全部协议。
4. 脚本写入该用户的协议授权，检查配置、重启核心，并刷新已配置的订阅。

只向所选入站添加这个账号，不会重建其他用户。支持同一核心内的组合，也支持 Xray 与已安装 Hysteria2、TUIC 等入站之间的组合。

尚未配置订阅时，使用 `6.生成/更新订阅` 完成一次订阅配置。之后添加用户可以复用已有订阅服务。

用户名沿用原脚本的订阅命名规则：第一个 `-` 之前的部分是订阅用户键。例如 `alice-phone` 的用户键为 `alice`。可直接使用 `alice`、`bob` 等名称。

## 修改已有用户

主菜单 `7.用户管理` → `7.修改用户协议（从已安装列表选择）` → 选择用户 → 输入当前列表编号。

修改时回车保留当前组合。UUID、订阅用户键和现有 Salt 保持原值；手机需要更新订阅。被取消授权的入站会删除这个账号，旧节点即使还缓存在客户端，也无法继续使用这个账号连接。

## 查看、删除

主菜单 `7.用户管理` → `8.查看全部用户协议`：一次列出所有用户及其实际已授权的协议名称，编号对应当前已安装列表。此操作只读取配置，不会刷新订阅或重启核心。

- `7.用户管理` → `1.查看账号` 或 `2.查看订阅`：按用户查看。
- `7.用户管理` → `5.删除用户`：从已安装的可管理入站中删除该账号，包括只使用某一种协议的用户。

配置检查或重启失败时恢复修改前的配置。成功提交会重启核心，现有连接可能短暂中断。

## 部署到已有服务器

本地修改不会自动同步到 VPS。替换管理脚本后，从用户管理菜单操作即可，继续使用当前可以连接 iPhone 的 Xray 核心。

在本地仓库目录上传修改版（替换实际 SSH 地址和端口）：

```bash
scp -P SSH端口 install.sh root@服务器IP:/root/install-user-protocols.sh
```

在服务器上先备份脚本和已有核心配置，再替换脚本：

```bash
backup_dir="/root/v2ray-agent-users-backup-$(date +%Y%m%d-%H%M%S)"
mkdir -m 700 "$backup_dir"
cp -p /etc/v2ray-agent/install.sh "$backup_dir/install.sh"
for core in xray sing-box; do
    if [[ -d "/etc/v2ray-agent/$core/conf" ]]; then
        cp -a "/etc/v2ray-agent/$core/conf" "$backup_dir/$core-conf"
    fi
done
bash -n /root/install-user-protocols.sh
install -m 700 /root/install-user-protocols.sh /etc/v2ray-agent/install.sh
bash /etc/v2ray-agent/install.sh
```

主菜单 `17.更新脚本` 会从上游下载并覆盖这个本地修改版。

授权保存在各协议的用户数组中。重装或重新初始化协议仍使用原脚本的账号同步逻辑，之后需要重新检查用户的协议授权。

如果配置了“其他远程订阅”，原脚本仍会合并它们；本功能控制本机已安装入站的账号授权。

## 本地验证

依赖 Python 3.9+、Bash、jq。在仓库目录执行：

```bash
bash -n install.sh
python3 shell/test_user_protocols.py
```

26 项隔离测试覆盖动态发现/移除已安装协议、超过 9 个选项、多入站共用一个配置文件、空用户列表、Xray 与 sing-box 跨核心组合、各协议认证字段、默认订阅与 Clash 节点生成、原三协议的 7 种组合及 49 种组合切换、菜单增改删、全部用户协议概览及授权变更后的显示、重复用户检查、批量添加后刷新和失败恢复。

测试使用临时配置和模拟的核心检查/重启，没有连接真实 VPS。
